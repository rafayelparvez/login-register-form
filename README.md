## 📖 About

A front-end authentication UI that lets users switch between **Login** and **Register** screens on a single page. It's a practice project focused on form layout, responsive design and basic JavaScript interactivity.

> This is a front-end only project. It does not connect to a backend or database.

## ✨ Features

- 🔁 **Login / Register toggle**: switch between the two forms without leaving the page
- 📱 **Fully responsive**: works on mobile, tablet and desktop
- 🎨 **Clean, modern UI**: simple layout focused on usability
- ⚡ **Lightweight**: no frameworks or dependencies, just plain HTML, CSS and JavaScript

## 🛠️ Built With

| Technology | Purpose |
|---|---|
| **HTML5** | Form structure and semantics |
| **CSS3** | Styling, layout and responsiveness |
| **JavaScript (ES6+)** | Switching between login and register views |

## 🚀 Getting Started

Run the project locally:

```bash
# 1. Clone the repository
git clone https://github.com/rafayelparvez/login-register-form.git

# 2. Move into the project folder
cd login-register-form

# 3. Open index.html in your browser
```

No installation or build step required.
